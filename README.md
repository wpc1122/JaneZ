# 张靓颖 Jane Zhang · 明星资料站

一个纯静态、零依赖的明星资料站，参考 [jujingyi.github.io](https://jujingyi.github.io/) 的版式结构（News / Resume / Music / Movie / Gallery / Contact），结合张靓颖的作品特点做了模块扩展。

## 目录结构

```
zhangliangying/
├── index.html              # 主页面（单页锚点导航）
├── assets/
│   ├── css/style.css       # 全部样式（含深浅两套主题变量）
│   └── js/
│       ├── data.js         # 数据层：所有人物资料都在这里，改内容只需改这一个文件
│       └── main.js         # 渲染与交互逻辑
└── README.md
```

## 页面模块

| 模块 | 说明 |
| --- | --- |
| Hero | 首屏标题、身份、代表语录、核心数据 |
| News 最新动态 | 2025—2026 年重要动态卡片 |
| Profile 个人档案 | 16 项基本信息参数表 + 个人简介 |
| Journey 星路历程 | 1984—2026 双列时间线 |
| Music 音乐作品 | 15 张专辑（可按录音室/EP/现场/精选筛选）、18 首影视金曲 OST、6 首英文作品 |
| Tour 巡回演唱会 | 7 轮巡演，含「追」进行中标记 |
| Awards 荣誉记录 | 29 条奖项，可按 5 类筛选 |
| Screen 影像与舞台 | 参演影视/音乐剧 + 常驻综艺 |
| Gallery 光影瞬间 | 9 宫格图集 + 灯箱（支持键盘左右切换） |
| Contact 聆听与关注 | QQ音乐/网易云/酷狗/微博直达 |

交互：吸顶导航高亮、滚动进度条、滚动渐显、深浅色主题切换（记忆偏好）、移动端折叠菜单、专辑/奖项筛选、图集灯箱、回到顶部。

## 本地预览

## 关于图片

为避免肖像版权与外链失效问题，站点内所有封面、头像、图集均采用 CSS/SVG 生成的渐变视觉，不依赖任何外部图片。

如需替换为真实照片：

1. 把图片放入 `assets/img/`（例如 `album-01.jpg`、`gallery-01.jpg`）；
2. 在 `data.js` 对应条目里增加一个 `img` 字段；
3. 在 `main.js` 对应渲染函数中，把 `.ac-art` / `.gi-art` 的渐变容器换成 `<img src="...">` 即可。

使用真实艺人照片前，请确认已获得相应授权。
